# Farmacia DEMO — Android App

Progetto Android nativo wrapper della demo mobile.

## Output
GitHub Actions genera:

`app-debug.apk`

Il file viene pubblicato come artifact `Farmacia-DEMO-APK`.

## Pacchetto
`com.nomyra.farmaciademo.debug`

## Tecnologia
- Android WebView
- HTML/CSS/JS inclusi localmente nell'APK
- Nessun server richiesto per aprire la demo
- Funziona anche senza Cloudflare per la parte dimostrativa

## Nota commerciale
L'app è volutamente generica e usa il nome “Farmacia DEMO”.
Brand, funzioni e integrazioni definitive vengono personalizzati dopo l'approvazione del cliente.
