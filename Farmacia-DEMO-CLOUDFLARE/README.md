# Farmacia DEMO — Proposta sito + app

Demo funzionale generica pensata per presentare a una farmacia le possibilità del progetto,
senza mostrare un sito già costruito sul brand del cliente.

La demo illustra esperienza utente, catalogo, servizi, richieste, ritiro/consegna, loyalty,
promemoria, area personale, chat e dashboard interna.

Nome, logo, colori, immagini, testi, servizi e integrazioni sono dimostrativi.
La versione reale verrà progettata e personalizzata dopo l'approvazione del cliente.
